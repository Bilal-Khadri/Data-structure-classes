# Data Structure Classes

In this project, I implemented several data structure classes from scratch using C++ templates.

## Data Structures

- Dynamic Array
- Doubly Linked List
- Stack
- Queue

## Implementation

The Stack and Queue classes are implemented using the Dynamic Array class.

The project is written in C++ using template classes.

## Purpose

This project was created for practicing:

- OOP
- Templates
- Dynamic Memory
- Data Structures
- Classes and Inheritance/Composition
